# Pitch / video script — owner: WS6 (science review: WS3)

Duración objetivo: según reglas oficiales (ver CHECKLIST). Grabar con datos **reales**.

1. **Gancho (5 s)** — 1930: Clyde Tombaugh descubre Plutón alternando dos placas fotográficas. Hoy, SPHEREx
   fotografía todo el cielo en 102 colores infrarrojos, una y otra vez.
2. **Problema (10 s)** — Esos datos son públicos pero inaccesibles para casi todos: archivos de 66 MB, formatos
   científicos. ¿Cómo ve alguien "el cielo cambiando"?
3. **Demo (30–60 s)** — elegir un campo → blink → aparece un asteroide → reporte (conocido, a ~X UA, su
   espectro) → un candidato no confirmado y por qué no decimos "descubrimiento" → página de límites: qué tan
   lejos podría estar un Planeta X para que SPHEREx lo vea.
4. **Cómo funciona (10 s)** — pipeline sobre datos reales de IRSA, cruce con catálogos de JPL.
5. **Impacto (10 s)** — cualquiera puede explorar datos reales de una misión NASA activa; herramienta educativa
   y de ciencia ciudadana.
6. **Cierre (5 s)** — nombre + URL.
